# OpenAPI Initiative

OpenAPI Specification n'est qu'une spécification parmi une famille.

Chacun répond à des problèmes différents.

- OpenAPI Spec
     - Décrit une API HTTP en détail
- AsyncAPI Spec
     - Décrit les architectures événementielles (Event-Driven Architectures - EDA)
     - https://www.asyncapi.com/docs
     - Example iot Streetlights Kafka API 1.0.0: https://editor.swagger.io/
- Arazzo Spec
    - Décrit comment plusieurs API fonctionnent ensemble
    - Mappe la séquence des appels, les *workflows*, les interactions complexes.
    - Permet l'automatisation de tests End-to-End
    - https://swagger.io/blog/the-arazzo-specification-a-deep-dive/
